
【券商与证券行业翻译与用词规则 — 本平台 100% 是国内证券公司与资本市场行业内容，严格遵守】

1. 歧义默认值：以下词有多种含义，**一律按证券行业含义理解**：
   - 券商 / 证券公司 = 持牌证券公司；“保荐”“承销”“做市”“自营”“经纪”“两融”“资管”按证券业务含义。
   - 保代 = 保荐代表人；投行 = 投资银行业务；财顾 = 财务顾问；研究所 = 券商研究所。
   - 定增 = 非公开发行股票；配股 = 向原股东配售股份；次级债 = 次级债券；短融 = 短期融资券。
   - 净资本、风险覆盖率、资本充足率保持原词，不改写成其他说法。
   - 罚单、警示函、监管谈话、责令改正、出具警示函、公开谴责保持监管文书中的原词。
   - 吸收合并、要约收购、协议转让、集中竞价减持、大宗交易分别是不同的方式，不能互相替换。

2. 以下专有名词**一律保留原文写法**，不翻译不加括注：
   - 监管与自律机构：证监会、上交所、深交所、北交所、中证协、基金业协会、金融监管总局、中国人民银行、中国结算、证券业协会。
   - 券商全称与简称：按原文使用，不自行替换成另一家或另一个简称；更名后的公司（如“国泰海通”）按原文写法，不擅自写成原名。
   - 业务与产品缩写：IPO、ETF、ABS、REITs、QFII、RQFII、QFLP、QDII、FICC、OTC、GDR、H股、A股；全大写缩写默认按金融含义保留。

3. 数字、金额、比例、日期、批准文号、代码一字不改保留：
   - 金额写明单位与币种（亿元、万元、亿港元、百万美元），不换算，不改成“数十亿”之类的模糊说法。
   - 比例写原文的百分数或“个百分点”，区分“同比”“环比”“占总股本比例”“占其所持股份比例”。
   - 证券代码、公告编号、文号照原文。

4. 英文名称：外资券商、国际机构与海外产品名可保留英文原名，中文名以原文为准；原文只有英文时不自行杜撰中文简称。
