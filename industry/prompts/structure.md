三、主体 subjects：资料实际讨论的主体公司（不是顺带提及），用这些 id：{{entities}}。没有就给空数组。监管机构、交易所和行业协会不在名录里时不填，也不要用名录外的 id。名录里的公司都是证券公司：shzq 是上海证券有限责任公司，不是上海证券交易所，也不是《上海证券报》，写到交易所或报纸时不要填 shzq；资管、承销保荐等子公司填它们的母公司。

四、资料范围 scope：只根据这篇资料自身判断，不能从候选报道反推。
- single：核心报道只有一个具体发生，或围绕该发生的一项评论、分析、回应。同一批次公布的多张罚单、同一份公告里的多项议案，若是同一次决定或同一份文件，属于 single。没有具体发生的单一观点可以是 single，但 fact 为 null；不能用“讨论同一个议题”把多个发生合成 single。
- composite：正文实质性报道多个可以各自成条的发生：早报、晚报、周报、月报、行业盘点、多家券商的动态汇总、会议综述。先数清主体各自做了什么，再判 scope：共同公司、日期、会议或总标题都不能把它们变成一次发生。仅把其他券商或事件用作背景、比较或例证，正文仍集中于一个发生，则不是 composite。
- unknown：材料不足以辨认范围。不要仅凭标题词、篇幅或是否能抽到 fact 判断。

五、事实 fact：抽取本条资料当前报道的那次发生，供同事实归组使用：title（≤30 字），subject（做出动作的主体，如某家券商、证监会、交易所），action（本次动作），object（动作的具体对象），occurredAt（原文明示的本次动作发生日期 YYYY-MM-DD，未知为 null）。监管决定以做出决定的机构为 subject，被处罚的券商是 object 的一部分；券商公告以该券商为 subject；媒体报道以被报道的事实主体为 subject，不以媒体为主体。composite 必须为 null；没有可确认发生的观点稿也可为 null。
先分清当前动作与背景：
- 事件的阶段决定动作：筹划、拟、受理、获批、过户、完成是不同的动作，不能把“筹划”写成“完成”，也不能把前一阶段的日期当作本次动作的日期。
- 新写的评论、解读、复盘涉及既有事件时，抽取这次评论/解读及其明确新增内容，不能因正文回顾了事件而仍写“发布/处罚/获批”。
- 发布时间、抓取时间、被引用文章的时间不能补作当前动作的日期。“今天”“昨日”可结合本条原文发布时间解析；只有背景日期或没有明确日期时保持 null。
- 汇总性的数据页、名录与统计表，仅列出既有数据，不等于本次发布了新事实。没有原文明示的新动作时，scope 为 unknown、fact 为 null。
fact 非 null 时还包含 evidence 和 conditions：evidence 只复制支持核心事实的一句原文（≤600 字符，找不到为 null）；conditions 是最多 4 条决定结论适用范围的原文短句，每条只有 {"quote":"原文的一句连续短句（≤400字符）"}。本步骤不翻译、不概括条件，只摘录。
evidence 必须支持上面选定的当前动作。通读全文（包括文末的金额、比例、期限和附带条件）后，条件优先级为：1. 金额、比例、对象与期限；2. 生效日期与适用范围；3. 尚需满足的批准、审核或其他前提。不要用一般背景占用条件名额。没有明确条件才给 []，不把预告写成已生效。
每个 quote 只承载一句原文；不同位置的条件分别成项，不能串成一个段落。保持原文语言和字符；超过长度就选较短的完整句子。不要翻译、改写、省略中间文字或自行加入 ... / …；拼接的引文会被丢弃。quote 必须是收到的原文正文/帖子里能连续查到的文字，不来自标题、来源标签或译文。

输出前核对当前动作（优先于标题和宣传措辞）：标题里的“重磅”“官宣”“突发”不能覆盖正文明确的阶段与先后关系。正文若说此前已经公告、现在是后续进展，本次 action 和 fact.title 必须写这次的进展；没有明示本次动作发生在哪一天，occurredAt 必须为 null，不从文章发布时间补齐。
