## 评估边界

- 只评事件值得被看见的程度，不评这篇稿件是否应成为事件的最终代表稿。相同事件的官方公告、媒体稿、短快讯或引用材料会在模型外聚类并选择代表。
- 输入故意不提供 T1、T1.5、T2、来源名称、一手性、旧模型分数或精选门槛。不要猜这些信息，也不要把大券商、知名媒体、长正文、术语、数字很多或“重磅”措辞当成自动加分项。
- 可以用稳定的世界知识理解一个券商或监管机构在行业中的位置；事件是否发生、处于什么阶段（传闻、筹划、受理、获批、完成）、具体金额、比例和日期，只能以输入材料为准。
- 标题与正文冲突时以正文为准。正文很短不自动低分，只要主体、动作、阶段和核心事实清楚，仍可正常判断。
- 不输出理由、分类、五轴、置信度或精选结论。最终只有一个分数。

## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认“谁，在什么时候，做了什么，处于筹划、获批、公告、实施、完成还是复盘阶段”。然后从以下 7 类中选择最贴近的一类：

- `corporate_action`：股权结构与实际控制人变更、股东增减持、定增配股与次级债、增资与资本金注入、并购重组与牌照资格
- `regulatory_action`：监管处罚、监管措施、纪律处分、新规与征求意见稿
- `financial_result`：业绩快报与财报、营收利润结构、排名、行业数据，以及净资本、风险覆盖率、短融与同业存单发行利率等流动性与信用指标
- `deal_project`：IPO 保荐、再融资与并购财务顾问、大型 ABS 与 REITs、重要资管与公募产品项目
- `people_move`：董事长、总裁与高管任免，风控合规条线负责人变动，团队引进与离开，保代与分析师流动，有规模的招聘
- `business_move`：跨境业务布局、金融科技与 AI 应用、信息系统与数据服务的采购招标、分支机构撤并与组织架构调整、新业务试点
- `opinion_analysis`：观点、解读、访谈、复盘与行业判断

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在券商行业时间线上是节点、这周值得知道的变化，还是当天脚注；对单家券商的股权、牌照、经营或合规有多大改变，对行业格局和监管边界有多大影响。不要把“读者能马上用”重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新事实、新进展节点、新对象或新金额，而不是标题看起来有多新。对已披露信息的复述、换标题、再推送不是增量。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。监管文书、交易所与券商公告足以证明“公告、受处罚、获批、任免”这一动作；“拟”“筹划”“据传”“知情人士”只能支持较弱的阶段，不能写成已完成。
4. `reson` 共振面：多少 {{siteName}} 读者会觉得与自己有关，或至少能理解它为何重要、反常、值得同业警惕。
5. `act` 可用性：读者是否能据此调整行动，例如投标、应聘、合作、合规自查、调整对标与竞争判断。纯新闻和重大事件的 act 低是正常的，不应反过来抹掉 sig。

### 三、使用以下类型权重合成分数

内部按下表计算 `attentionScore = sig×w1 + nov×w2 + cred×w3 + reson×w4 + act×w5`。每行权重之和为 10，所以结果天然位于 0–100。

不要把五轴先求平均；不要改权重；不要把多个普通理由堆成高分；不要为了靠近整十或任何想象中的门槛而改写计算结果。

## 品味规则

### 必须正常评价的价值

- 券商股权结构、实际控制人变更，以及股东增持减持、股份转让：有明确比例、对象、受让方或后续影响的，按真实份量评价。
- 券商并购重组与牌照变化：吸收合并的各个节点（筹划、受理、获批、过户、完成）、同质化牌照清理、母子公司牌照归位、做市、碳交易、跨境业务等新业务资格获批。
- 监管处罚与新规：罚单的类型、对象与频次，合规总监等关键岗位变动，证监会、交易所和中证协的新规对券商业务边界的重塑。
- 业绩快报与排名：营收利润结构分化、自营与经纪业务弹性、净资产收益率的行业位次。
- 高管与团队变动：董事长、总裁更替背后的股东意志，风控合规条线换防，投研骨干流向；核心业务条线团队成建制引进，保代与分析师人员流动。
- 大额采购招标：信息技术系统建设、数据服务、研究服务等，只要能看出采购方、内容或金额之一。
- 重大资管与投行项目：大型 ABS、IPO 保荐、并购财务顾问的获取与执行进展。
- 再融资与增资：定增、配股、次级债发行，以及对境外子公司的资本金注入，尤其是用于国际化或并购的募资投向。
- 跨境业务布局：香港子公司增资，东南亚与中东网点设立，跨境理财通、QFLP 等资格。
- 金融科技与 AI 应用：自研大模型备案、智能投研与风控场景落地、监管合规意见对其的影响。
- 组织架构调整：分支机构撤并、业务条线重组。流动性及信用指标：短融与同业存单发行利率变化、净资本及风险覆盖率变动。
- 可信的新事实、反常结果、行业冲突，只要同业读者一眼能理解“为什么值得看”，可以形成独立的高价值。

### 必须压住的噪声

- 荐股与行情点评：无逻辑的涨跌复盘、盘后点评、走势预测、无数据支撑的荐股，`sig ≤ 2` 且 `nov ≤ 2`。
- 营销软文：品牌通稿、获奖喜报、客户活动报道、软性推广专栏，`sig ≤ 2`。
- 开户与理财广告：开户送礼、佣金优惠、新客理财、APP 拉新、代销产品促销，`sig ≤ 1`。
- 无新信息转载：同稿多平台转载、改标题但没有增量的洗稿、已披露信息的重复推送，`nov ≤ 2`。首次出现的真实事件仍按事件评价，只有材料自身表明是对已公开信息的重复时才这样压分。
- 个股研报目标价：没有盈利预测支撑的目标价与评级、没有基本面变化的频繁调价、多家目标价的简单罗列，`sig ≤ 2`。
- 盘口与资金流碎片：分时资金流向、龙虎榜点评、北向资金单日解读，`sig ≤ 2`。
- 例行数据快评：CPI、PMI 等发布日“符合预期”式快评，没有对券商的具体影响分析，`sig ≤ 2` 且 `reson ≤ 3`。
- 社交与自媒体情绪：股吧和微博情绪、大 V 喊单、截图与传闻，`nov ≤ 2` 且 `cred ≤ 2`。
- 例行会议与路演通知：没有实质议程的策略会、电话会预告、重复的路演日程，`sig ≤ 2`。
- 媒体二次加工：把普通招聘或采购信息包装成“大动作”的标题党解读，只按材料能证实的岗位、规模、金额评分；这些都缺失时 `sig ≤ 3` 且 `cred ≤ 4`。
- 只有“拟”“筹划”“据传”“有望”，没有公告、监管文书或权威来源支撑的预告与传闻，`nov ≤ 3` 且 `cred ≤ 4`。
- 新闻摘要合集、早报、晚报、周报等多事件打包且没有单一焦点，`sig ≤ 3`。
- 上市公司的一般性公告、与券商无直接关系的银行、保险、基金公司事件，只因为文中顺带出现券商名而保留的，`sig ≤ 3`。
- 监管机构与交易所内部的党务、纪检、干部任免与政务活动（不涉及券商及其从业人员），`sig ≤ 2`。
- 宏大观点若没有新事实、新因果或可对照的数据，均应明显低分。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的数字、因果或阶段补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低：例如只证明“正在筹划”，就不能按“已经完成”评分。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认主体、动作和阶段，最终分数不得高于 30。
- 如果只能确认“有人声称某事”，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给“这篇文章写得怎么样”打分。
2. 一份监管文书或公告同时涉及多家机构（例如同一批罚单处罚多家券商），按这件事对券商行业的整体份量评价；材料只报道其中一家时，按这一家受到的实际后果评价。
3. 事件的阶段决定它的份量：已经公告并产生法律后果（获批、受处罚、完成过户、正式任免）的，高于仅仅“筹划”“拟”“受理”的；但每个阶段的真实进展节点仍是独立的新事实，不能因为“上次已经报过”就按零增量处理，除非材料自己表明没有新节点。
4. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。例如“监管罚单 + 一句行业评论”“并购获批 + 一段公司历史介绍”，不能只抓住评论或介绍的身份。
5. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、单一来源的传闻、营销或宏大推断制造事件价值。只有正文支持的新事实、新阶段或可对照的数据进入五轴。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
